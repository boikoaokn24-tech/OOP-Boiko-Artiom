## Висновок

Під час виконання лабораторної роботи №9 було досліджено та практично застосовано принципи поліморфізму, абстрактних класів та обробки винятків (try-catch) у мові програмування C# (.NET SDK).

На прикладі ієрархії класів сповіщень Notification -> EmailNotification, SMSNotification, PushNotification (Варіант 1) було реалізовано:
1. Абстрактний базовий клас Notification з поліморфними методами Send() та Validate().
2. Похідні класи, які реалізують специфічну логіку валідації та відправки для кожного типу сповіщень.
3. Клас-сервіс NotificationService для масової обробки колекції сповіщень із безпечним перехопленням помилок за допомогою блоку try-catch.

У результаті виконання програми продемонстровано, що поліморфні виклики дозволяють гнучко обробляти різні типи об'єктів у єдиному циклі, а механізм винятків коректно запобігає аварійному завершенню програми при передачі невалідних даних (некоректних email-адрес чи номерів телефонів).

Робота підтвердила переваги об'єктно-орієнтованого програмування для створення надійного, розширюваного та захищеного від помилок коду.
